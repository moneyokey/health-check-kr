# 건강검진 결과 해석 웹앱 MVP

대한민국 건강검진 기준으로 내 건강 수치를 쉽게 이해할 수 있는 웹 앱입니다.

## 🚀 실행 방법

### 1. 브라우저에서 바로 실행 (권장)
```bash
# 방법 1: 파일을 더블클릭하여 브라우저에서 열기
open index.html  # macOS
xdg-open index.html  # Linux
start index.html  # Windows

# 방법 2: 간단한 HTTP 서버 사용 (선택사항)
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

### 2. 검증 실행
```bash
# 로직 테스트 (35개 단위 테스트)
node test.js

# JavaScript 문법 검사
node -c health-analyzer.js
```

## ✅ 구현된 기능

### 입력 가능한 수치
- ✅ **공복혈당** (mg/dL)
- ✅ **총 콜레스테롤** (mg/dL)
- ✅ **HDL 콜레스테롤** (좋은 콜레스테롤, mg/dL)
- ✅ **LDL 콜레스테롤** (나쁜 콜레스테롤, mg/dL)
- ✅ **중성지방** (mg/dL)
- ✅ **AST** (간수치, U/L)
- ✅ **ALT** (간수치, U/L)
- ✅ **혈압** (수축기/이완기, mmHg)
- ✅ **BMI** (체질량지수, kg/m²)

### 주요 기능
- ✅ **실시간 분석**: 입력 즉시 정상/주의/위험 구간 판정
- ✅ **색상 표시**: 초록(정상), 주황(주의), 빨강(위험)
- ✅ **쉬운 설명**: 각 수치에 대한 한국어 해석 제공
- ✅ **정상 범위 표시**: 각 항목의 정상 기준치 안내
- ✅ **모바일 우선 디자인**: 반응형 레이아웃
- ✅ **다크모드 지원**: 시스템 설정에 따라 자동 전환
- ✅ **의료 고지 표시**: "참고용이며 의료 조언 아님" 명시
- ✅ **출처 표기**: 대한민국 의료 기관 가이드라인 명시

### 기준 출처
- **공복혈당**: 대한당뇨병학회 진료지침 2021
- **콜레스테롤**: 한국지질·동맥경화학회 이상지질혈증 치료지침 2022
- **간수치**: 대한간학회 가이드라인
- **혈압**: 대한고혈압학회 고혈압 진료지침 2022
- **BMI**: 대한비만학회 비만 진료지침 2022 (아시아-태평양 기준)

## ✅ 되는 것

1. ✅ **오프라인 동작**: 인터넷 없이 브라우저에서 실행 가능
2. ✅ **즉시 사용 가능**: 설치나 설정 불필요
3. ✅ **정확한 계산**: 35개 단위 테스트로 검증됨
4. ✅ **모바일 친화적**: 작은 화면에서도 잘 보임
5. ✅ **다크모드**: 시스템 설정 자동 반영
6. ✅ **부분 입력 지원**: 원하는 항목만 입력해도 됨
7. ✅ **경계값 정확도**: 99 vs 100, 125 vs 126 등 정확히 구분

## ⚠️ 제한 사항 (안 되는 것)

1. ❌ **데이터 저장 안 됨**: 새로고침하면 입력값 사라짐
   - 해결: 브라우저 localStorage 추가 필요
2. ❌ **기록 관리 없음**: 시간에 따른 변화 추적 불가
   - 해결: 차트 라이브러리와 저장소 필요
3. ❌ **PDF 출력 없음**: 결과를 파일로 저장 불가
   - 해결: Print CSS 또는 jsPDF 라이브러리 필요
4. ❌ **다국어 미지원**: 한국어만 지원
5. ❌ **개인화된 조언 없음**: 나이, 성별, 병력 고려 안 함
   - 해결: 추가 입력 폼과 세밀한 기준 필요
6. ❌ **의료진 리뷰 없음**: 실제 의료 조언 아님 (고지 포함)
